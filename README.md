# 隔壁同樂室｜遊戲規則

## 五子棋

- 使用 19×19 棋盤，黑棋先行，雙方輪流在空交叉點落下一子。
- 橫、直或斜線率先連成五枚同色棋子者獲勝。
- 單人模式可以悔棋；系列賽每局交換黑白先後手。

## 中國象棋

- 紅方先行；車走直線、馬走日、象走田、士守九宮，炮隔一子吃棋。
- 將與帥不能在同一直線直接照面。
- 將死或困斃對方將帥者獲勝。

## 黑白棋

- 落子時必須至少在一個方向夾住對方棋子，所有被夾住的棋子翻成己方顏色。
- 沒有合法落點時跳過；雙方都無合法落點時結束。
- 結束時棋子數量較多者獲勝。

## 中國跳棋

- 使用邊長 5 格的三角營區，可進行 2～3 人遊戲。
- 每回合可移到相鄰空位，或跨過相鄰棋子跳到後方空位；一次回合可以連續跳躍。
- 棋子不能進入其他玩家的起始營區；率先讓自己的 15 枚棋子全部越過中央線者獲勝。

## 麻將

- 使用不含花牌的 136 張牌，每位玩家起手 13 張。
- 輪到自己時摸一張，再打出一張。
- 湊成四組順子或刻子，加上一對將牌即可自摸胡牌。

## 大老二

- 持有方塊 3 的玩家先攻，可出單張、對子、三條或合法五張牌型。
- 點數順序由 3 到 2；必須以相同張數與牌型壓過桌面牌組，否則選擇過牌。
- 最先出完全部手牌者獲勝。

## 暗棋

- 第一枚翻開的棋子決定玩家陣營。
- 一般棋子每次移動一格；炮必須隔一枚棋子才能吃子。
- 依棋子階級吃子，兵可以吃將而將不能吃兵；消滅對方棋子者獲勝。

## 西洋棋

- 白方先行，各棋子依國際西洋棋規則移動。
- 支援王車易位、吃過路兵與兵升變。
- 將死對方國王者獲勝；無合法移動但未被將軍時為和棋。

## 圍棋

- 使用 13×13 棋盤，黑棋先行，雙方輪流落子。
- 完全包圍沒有氣的棋串即可提子；禁止自殺落子及立即還原上一局面的打劫。
- 雙方連續停一手後結束，以中國面積法計分。

## 二十一點

- A 可以算 1 或 11，J、Q、K 算 10 點，其餘依牌面計分。
- 玩家可以補牌或停牌；超過 21 點立即爆牌。
- 莊家 16 點以下補牌、17 點以上停牌；未爆牌且點數高於莊家者獲勝。

## 撿紅點

- 輪流打出一張手牌；數字牌與桌面牌合計為 10 時可以吃牌，J、Q、K 必須同字配對。
- 紅 A 為 20 分，其餘紅牌依牌面計分。
- 牌局結束時分數最高者獲勝。

## 九九

- 玩家輪流出牌，累計點數不能超過 99。
- A 可加 1 或 11、4 反轉、10 加減 10、J 跳過、Q 加 20、K 將點數設為 99。
- 沒有合法牌可出者淘汰，最後留下的玩家獲勝。

## 俄羅斯方塊

- 使用方向鍵左右移動，↑ 旋轉，↓ 軟降，空白鍵快速落下。
- 完整填滿一行後會消除並計分；畫面會預告下一個方塊。
- 方塊堆到頂端時結束；雙人模式比較消除行數與分數。

## 皮卡丘排球

- 玩家 1 使用方向鍵移動、↑ 跳躍、空白鍵攻擊；玩家 2 使用 W／A／S／D 與 F 或 Enter。
- 空中攻擊搭配方向鍵可以打出平殺、斜上或斜下殺球；地面方向鍵加攻擊可以撲救。
- 球落在己方場地時對手得分，先得到 7 分者獲勝；每局重新倒數後開球。

## 賽車障礙

- 玩家 1 使用方向鍵，玩家 2 使用 W／A／S／D 控制車輛。
- 避開三角錐、油漬與路障；碰撞會失去一點耐久。
- 到達終點或有玩家耗盡耐久時結束，以剩餘耐久及分數判定勝負。

## 隔壁打磚塊

- 使用左右方向鍵移動玩家 1 板子，空白鍵發球；玩家 2 使用 A／D 移動，F 或 Enter 發球。
- 開局倒數結束後需要手動發球；掉球重生後也必須再次按發球鍵。
- 經典模式有三條生命、道具與 Boss 關；合作模式共用生命；對戰模式率先清空自己半場者獲勝。
